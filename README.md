# 臺灣地震 3D 語音導覽

問一句話，AI 即時生成一分鐘導覽：鏡頭飛到該區域、時間軸跟著播放、同步語音解說。資料為 1990–2026 年中央氣象署地震目錄（圖框內 73,683 筆）。

- **線上試用**：https://nutcelvischen-jpg.github.io/earthquake_ec/
- **宣傳片**：[taiwan_quake_tour_promo_v2_web.mp4](taiwan_quake_tour_promo_v2_web.mp4)（57 秒）

## 怎麼用

1. 用 **Chrome** 開啟線上試用網址。
2. 在右上角「問地震」貼上你自己的 OpenRouter API key（到 <https://openrouter.ai/keys> 申請），按「儲存」。
3. 按麥克風說話，或直接打字，例如：
   - 用一分鐘帶我看懂臺灣的板塊與地震
   - 為什麼東部的地震特別多？
   - 921 大地震
   - 臺灣的深層地震都發生在哪裡？
4. 導覽進行中可以按「暫停／下一幕／結束」，也可以隨時問新問題。

key 只存在你這台電腦的瀏覽器（localStorage），不會上傳到本網站；提問時由瀏覽器直接送到 OpenRouter。每次提問約花費 0.001–0.002 美元（預設模型 `anthropic/claude-haiku-5.5`，可在網址後加 `?model=模型代碼` 更換）。使用公用電腦時，離開前請按「更換 key」清掉或改用無痕視窗。

## 畫面說明

- 圓點顏色為震源深度，大小為規模；白色細線標出規模 6 以上地震由地表到震源的位置。
- 橘紅線為板塊邊界，帶齒的是海溝，齒尖指向上方的板塊。
- 半透明曲面為隱沒板塊面，流動條紋表示下沉方向。
- 導覽講到某個區域時，區域外會變暗，左側數字與下方年度長條圖也只統計該區域。

## 資料來源與限制

| 項目 | 來源 | 說明 |
|---|---|---|
| 地震目錄 | 中央氣象署 | 1990-01 至 2026-11，圖框 119–124°E、21–26°N |
| 陸地地形 | 內政部 20 公尺網格數值地形模型 | 經 [OsmHackTW/terrain-rgb](https://github.com/OsmHackTW/terrain-rgb) 圖磚重新取樣 |
| 海底地形 | ETOPO1 降至 10 角分 | 解析度粗，僅為示意 |
| 海溝與變形前緣 | Bird (2003) PB2002 全球板塊邊界 | 花東縱谷縫合帶為示意手繪 |
| 隱沒板塊面 | 由本目錄的震源深度擬合 | 示意用趨勢面，並非正式地質模型 |

- 陸地高度誇大顯示（預設 6 倍）；海平面以下的海底地形與震源為同一比例。
- 解說中的日期、規模、深度、筆數取自資料；板塊機制等背景說明由語言模型依據內建的區域資料卡產生，仍可能有誤，正式引用前請查證。
- 語音辨識與朗讀使用瀏覽器內建功能，建議使用 Chrome。
